# 多引擎搜索聚合

用 `web_search` 一次性并行查询多个搜索引擎，汇总去重后交给用户。目的是**用一次调用换到多来源的视角**，而不是逐家去搜。

## 何时用

- 需要联网才能回答的问题（新闻、版本号、库的最新用法、价格、赛事、人物近况）。
- 用户说"搜一下""帮我查""上网找找""有没有相关资料"。
- 单一来源不足以下结论，需要交叉验证（比如"这个库还维护吗"，看 GitHub + 搜索引擎 + 官方文档）。
- 想知道**中文圈和英文圈分别怎么说**（大陆引擎 + 境外引擎同时覆盖）。

不需要用：代码库内部的问题（用 grep/读文件）、纯推理或计算、用户已经给了全部材料。

## 怎么用

```
web_search(query: "关键词", limit: 5)
```

常用参数：

| 参数 | 说明 |
| --- | --- |
| `query` | 必填。关键词，中英文都行。 |
| `engines` | 只查指定引擎，例如 `["baidu","github"]`。默认自动选当前可达的全部。 |
| `limit` | 每个引擎取几条，默认 5。要广撒网用 10，要快速看结论用 3。 |
| `mode` | `group`（默认，按引擎分组，便于对比来源）或 `interleave`（交错混排，便于通读）。 |
| `force` | 忽略"近期不可达"缓存，强制重试全部引擎。网络刚恢复时用。 |

另有 `search_engines`：查看各引擎当前可达状态；`probe: true` 会实际发探测请求，用于确认外网/代理是否通。

## 引擎特性（影响怎么解读结果）

| 引擎 | 区域 | 说明 |
| --- | --- | --- |
| 百度 | 大陆，直连 | 中文网页覆盖面最好。 |
| 必应 | 大陆，直连 | 走官方 RSS 通道，中英文皆可，摘要质量高。 |
| 360搜索 | 大陆，直连 | 中文补充来源。 |
| 搜狗 | 大陆，直连 | 能搜到微信公众号内容。**按 IP 限流**，连续检索会触发验证码并临时不可用。 |
| GitHub | 需代理/可直连 | 搜的是**仓库**（按相关性排序），不是代码内容；适合找项目、库、工具。**对中文关键词很不敏感**——实测 "python 装饰器用法" 返回 0 条，换成 "python decorator" 就有 5 条，所以查 GitHub 时尽量用英文关键词。 |
| Google | 需代理 | **走的是 Google 新闻 RSS，结果只有新闻条目**，不是网页搜索，链接是 news.google.com 的跳转地址。冷门或技术性很强的词在新闻索引里可能一条都没有，这是正常的，不代表工具坏了。 |
| Yahoo | 需代理 | 网页搜索，偶尔返回 500 或挑战页，调用端已有重试。 |
| DuckDuckGo | 需代理 | 网页搜索，需要完整浏览器指纹头，偶尔给空壳页。 |

**外网不可达时**：Google / Yahoo / DuckDuckGo 会失败并被自动记入"近期不可达"，后续检索直接跳过（不再重复等超时），等价于只用大陆搜索。这不是故障，是预期行为；网络恢复后用 `force: true` 重新探测。

## 结果怎么用

- **引用要给出来源**：说明结论来自哪个引擎/哪个网站，不要只说"网上说"。
- **同一 URL 已跨引擎去重**：出现在第一个命中的引擎下，`duplicates` 字段记录去重条数。
- **注意结果相关性**：搜索引擎有时会给出无关内容，尤其当关键词冷门或含歧义时。取结果前先核对标题/摘要是否真的对题；不对劲就换关键词重搜，不要硬用。
- **某家返回 0 条不等于坏了**：GitHub 对中文词不敏感、Google 只有新闻条目、窄关键词（完整的疑问句）在各家都可能没结果。这时应该换更短、更通用的关键词（GitHub 尤其要换英文），而不是断定工具失效。
- **失败要说清楚**：如果某个引擎报"触发验证码""被限流""空壳页"，如实告诉用户这家这次没查到，不要假装覆盖了全部来源。被拦截的引擎会自动冷却一段时间（网络故障 5 分钟、反爬拦截 15 分钟）再自动重试。
- 搜索结果只是线索，**关键事实（API 签名、版本号、行为）应点开原始页面确认**再作为结论。

## 注意

- 不要用本工具去抓取需要登录才能看的内容，也不要用它做绕过站点访问控制的尝试。
- 检索频率别拉太满：搜狗、GitHub 都有明确的限流，连续大批量查询会触发拦截（GitHub 未认证 API 是 10 次/分钟）。
- 结果是"当前这一时刻"的页面，站点改版会导致某个引擎解析失效。若某个引擎持续返回 0 条但状态是可达，多半是它的页面结构变了，应该报告而不是反复重试。
